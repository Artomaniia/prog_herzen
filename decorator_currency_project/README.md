# Лабораторная работа 2: паттерн «Декоратор»

## Описание

Проект показывает простой пример использования паттерна **Decorator** на задаче получения курсов валют.

Базовый компонент получает данные о курсах валют в формате JSON. Затем конкретные декораторы преобразуют эти же данные в другие форматы:

- `YamlCurrencyRatesDecorator` — преобразует данные в YAML;
- `CsvCurrencyRatesDecorator` — преобразует данные в CSV.

Также каждый компонент умеет сохранять результат в файл соответствующего формата.

## Что реализовано

- общий интерфейс через `ABC` и `@abstractmethod`;
- базовый компонент `CbrCurrencyRates`;
- базовый класс декоратора `CurrencyRatesDecorator`;
- конкретный декоратор для YAML;
- конкретный декоратор для CSV;
- сохранение результата в `.json`, `.yaml` и `.csv`;
- тесты через `unittest`;
- документация в стиле PEP-257;
- аннотации типов в стиле PEP-484.

## Как работает паттерн

В проекте есть общий интерфейс `CurrencyRatesComponent`. С ним могут работать и обычные компоненты, и декораторы.

`CbrCurrencyRates` получает данные и возвращает их в JSON-формате.

Декораторы принимают объект компонента внутрь себя и не меняют исходный класс. Они просто добавляют новое поведение:

```python
rates = CbrCurrencyRates()
yaml_rates = YamlCurrencyRatesDecorator(rates)
csv_rates = CsvCurrencyRatesDecorator(rates)
```

То есть исходный компонент остается тем же, но мы можем получить другой формат результата.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск примера

```bash
python main.py
```

После запуска будут созданы файлы:

- `rates.json`;
- `rates.yaml`;
- `rates.csv`.

## Запуск тестов

```bash
python -m unittest test_currency_rates.py
```

## Примечание

В тестах используется заранее подготовленный словарь с курсами валют. Это сделано специально, чтобы тесты не зависели от интернета и всегда проходили одинаково.
