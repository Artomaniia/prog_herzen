# Построение бинарного дерева

## Описание задания

Необходимо разработать программу на языке Python, которая строит бинарное дерево. Бинарное дерево — это структура данных, в каждом узле которой может быть не больше двух потомков: левый и правый.

Базовый вариант отображения результата — вложенный словарь. Дополнительно в работе рассмотрены другие контейнеры для хранения дерева, включая структуры из модуля `collections`.

## Используемый вариант

В проекте реализован только вариант №9:

```text
Root = 9
height = 6
left_leaf = root * 2 + 1
right_leaf = 2 * root - 1
```

## Что реализовано

В проекте реализована рекурсивная функция:

```python
from binary_tree import gen_bin_tree

tree = gen_bin_tree()
print(tree)
```

Функция строит дерево по следующему принципу:

1. В корневой узел помещается значение `root`.
2. Для каждого узла вычисляются левый и правый потомки по формулам варианта №9.
3. Для потомков рекурсивно строятся поддеревья.
4. Рекурсия останавливается, когда достигнута заданная высота дерева.

Если `height` и `root` переданы при вызове функции, используются именно они. Если параметры не переданы, берутся значения варианта №9: `root = 9`, `height = 6`.

Пример вызова с параметрами по умолчанию:

```python
from binary_tree import gen_bin_tree

tree = gen_bin_tree()
```

Пример вызова с собственными параметрами:

```python
from binary_tree import gen_bin_tree

tree = gen_bin_tree(height=3, root=10)
```

Для `root = 10` левый потомок будет равен `21`, а правый — `19`.

## Поддерживаемые контейнеры

Функция `gen_bin_tree` поддерживает несколько способов хранения дерева:

| Значение `container` | Структура |
| --- | --- |
| `"dict"` | вложенные словари |
| `"list"` | вложенные списки |
| `"ordered_dict"` | `collections.OrderedDict` |
| `"defaultdict"` | `collections.defaultdict` |
| `"deque"` | `collections.deque` |

Пример:

```python
from binary_tree import gen_bin_tree

tree_as_dict = gen_bin_tree(height=3, container="dict")
tree_as_list = gen_bin_tree(height=3, container="list")
tree_as_deque = gen_bin_tree(height=3, container="deque")
```

## Проверяемые случаи

В тестах проверяется:

- построение дерева по варианту №9;
- использование значений по умолчанию `root = 9` и `height = 6`;
- использование переданных параметров `height` и `root`;
- корректное построение дерева высоты `1`;
- количество узлов в полном бинарном дереве;
- корректность формул для левого и правого потомка;
- обработка некорректной высоты дерева;
- построение дерева в разных контейнерах: `dict`, `list`, `OrderedDict`, `defaultdict`, `deque`.
